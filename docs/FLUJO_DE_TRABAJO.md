# Flujo de trabajo

- Cada conversación de ChatGPT dentro del proyecto corresponde a un reto.
- El reto llega con un enunciado, la tecnología y un tiempo estimado de 15–30 minutos.
- Se entrega el enunciado sin pistas ni solución. Oscar pedirá pistas o ayuda si las necesita.
- La implementación del reto se desarrolla en este repositorio.
- Al compartir la solución, se revisan el razonamiento, el diseño y el código. La revisión debe adaptarse a la experiencia que vaya mostrando Oscar.
- Los retos alternan C#/.NET y C++, con frecuencia ajustada según la evolución.
- Los temas deben conectar con sus intereses: videojuegos, Unity, herramientas de desarrollo, IA y aplicaciones .NET.

## Tecnologías posibles

- C# con .NET de consola
- Unity
- Blazor
- ASP.NET Core
- C++
