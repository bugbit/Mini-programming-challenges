# Mini retos de programación

Retos de 15–30 minutos para practicar el razonamiento y la resolución de problemas antes de escribir código. Las tecnologías incluyen C#/.NET (consola, Unity, Blazor y ASP.NET Core) y C++.

## Cómo funciona

Cada conversación del proyecto corresponde a un reto. Recibirás el enunciado sin pistas ni solución. Cuando compartas tu implementación, revisaremos el razonamiento y el código, y ajustaré la dificultad de los siguientes retos a tu evolución.

Consulta el [flujo de trabajo](docs/FLUJO_DE_TRABAJO.md) y la [guía de ayuda y revisión](docs/AYUDA_Y_REVISION.md).

## Retos

- [Reto 1: Inventario de pociones](retos/001-inventario-pociones/README.md) — C#/.NET de consola.
- [Reto 2: Sistema de eventos con prioridades](retos/002-sistema-eventos-prioridades/README.md) — C#/.NET de consola.
- [Reto 3: Movimiento con deshacer y rehacer](retos/003-movimiento-deshacer-rehacer/README.md) — C++17 de consola.
- [Reto 4: Fabricación de objetos](retos/004-fabricacion-objetos/README.md) — C#/.NET de consola.

Las pistas están en un archivo separado dentro de cada reto. Puedes pedirlas cuando quieras.

## Estructura

- `retos/`: enunciados y pistas, un directorio por reto.
- `docs/`: flujo de trabajo y plantillas.
- La implementación se añade al repositorio como parte del trabajo de cada reto.
